# Changelog

## 2026-08-26

- 新增真实后端 REST API 设计文档，拆分学生、座位、高频状态、聚合统计及各类台账接口。
- 将“排座位”升级为可交互、可调整尺寸的拼豆座位板，默认尺寸为 30 x 30。
- 座位板从已导入的学生花名册读取学生，并使用学生 ID 关联座位，支持同名学生。
- 持久化座位板行数、列数和学生坐标，兼容 PC 拖放及移动端点选操作。
- 在座位网格顶部增加自动居中的讲台标志，调整列数或滚动时保持教室方向关系。
- 使用本地填色桌椅与讲台插画替换线框座位，并按每两列一组自动生成教室过道。
- 将固定列数改为结构化座位组编辑器，支持自由增减分组并自动计算总列数与过道。
- 将低频布局设置收进 H5 兼容弹窗，合并学生人数统计，增加全部清空，并让桌椅插画继承当前主题颜色。
- 修复旧版浏览器内存数据缺少列分组时座位板初始化失败，并改进真实错误日志与图标降级处理。
- 修复 VS Code Live Server 向异步 HTML 模板内 SVG 注入脚本、导致座位网格节点丢失的问题。

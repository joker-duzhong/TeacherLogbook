# 教师台账 Web 设计系统

本文件替代此前自动生成的通用建议。儿童字体、订阅页布局和外部字体导入不适用于教师台账。

权威实现规范见 [Web 设计规范](../../apps/web/DESIGN.md)，产品边界见 [产品说明](../../apps/web/PRODUCT.md)。

- 组件：shadcn-vue（Reka UI）与 Tailwind CSS 4；组件源码位于 apps/web/src/components/ui。
- 视觉：暖白底色、灰绿侧栏、墨色文字、低饱和绿色主操作；保留小鸟标识，四种皮肤共享同一组件规范。
- 桌面：232px 分组导航、功能搜索、独立班级切换、页面操作、筛选栏与数据表格。
- 手机：760px 断点、44px 触控目标、抽屉导航、常用底栏、信息卡片和底部筛选。
- 表单：字段校验靠近输入、明确进度、保存失败保留输入、关闭前保护未保存内容。
- 数据操作：导入前检查、变更文件后重新检查、恢复与清空二次确认。
- 验证：隔离接口下的浏览器测试、桌面和手机截图、类型检查及生产构建。

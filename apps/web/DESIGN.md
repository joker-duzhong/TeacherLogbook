# Web 设计规范

## 已确认方向

温和、清晰的教育工作台。shadcn-vue / Tailwind 4 / Reka UI，保留系统中文字体与小鸟标识。腾讯 TDesign、字节 Arco 用作企业工具交互参考；不声称复制其页面。

## 色彩与密度

默认暖白 #F5F3EE，内容 #FFFEFA，灰绿侧栏 #EDF3ED，主色 #34776D，墨色 #17222B，辅助文字 #607078。橙色只用于提醒和品牌细节。通过 Web 自有语义变量适配原有四种皮肤；不改变用户保存的皮肤标识。

正文 14px / 1.6，辅助 12–13px，标题 26–28px。输入与按钮 PC 高 36–40px，移动端至少 44px。控件圆角 6–8px，表面 10–12px。分组间距 24px，关联操作间距 8px。

## 页面结构

桌面 232px 分组导航，顶部工具条包含班级切换与账号菜单，内容最大宽度 1440px。标题、说明、主操作形成单独标题区。记录筛选独立于新增/导出操作。表格内包含行号、正文、状态和明确的行操作。

移动端 760px 断点，16px 边距，独立卡片列表、底部筛选面板与完整可滚动表单。导航支持焦点约束、Escape、关闭后恢复焦点、触摸背景锁定。优先显示姓名/主题与关键字段，更多内容仍可查看。

## 交互

每页一个主要新增入口；搜索支持回车与清空。筛选可重置，结果注明数量。保存、删除、导入提供进度与结果；失败保留表单，字段错误靠近控件。弹窗保存时禁止重复提交与关闭，未保存编辑关闭前确认。数据页默认展开常用导入，低频迁移折叠，备份和危险区分离。

## 验证

验证 PC/手机、4 种皮肤、长文本、零数据、接口失败、键盘导航、数据增改删、登录往返和不重复写入；自动回归结合实际截图。
